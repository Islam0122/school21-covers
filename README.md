# Генератор обложек школы №21

Веб-приложение на React + Vite (JavaScript) для создания обложки «Окуучунун иши» по оригинальному шаблону. Дизайн шаблона не меняется: поверх него вписываются только ФИО, класс и учебный год. Всё работает в браузере, без backend, базы данных и API.

## Структура

```
school21-covers/
├── public/
│   └── Cover_Template.png   ← оригинальный шаблон (1087 × 1536)
├── src/
│   ├── App.jsx              ← интерфейс, валидация, скачивание
│   ├── App.css              ← стили и адаптивная вёрстка
│   ├── main.jsx             ← точка входа, подключение шрифта PT Serif
│   └── lib/
│       ├── cover.js         ← рисование обложки на Canvas, координаты линий
│       └── docx.js          ← экспорт в Word (A4, 1 страница, без полей)
├── index.html
├── package.json
└── vite.config.js
```

## Запуск локально

Нужен Node.js 18 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:5173.

Проверка собранной версии:

```bash
npm run build
npm run preview    # http://localhost:4173
```

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub, например `school21-covers`, и загрузите проект:

   ```bash
   git init
   git add .
   git commit -m "Генератор обложек школы №21"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/school21-covers.git
   git push -u origin main
   ```

2. Опубликуйте сайт:

   ```bash
   npm run deploy
   ```

   Команда соберёт проект (`predeploy` → `vite build`) и отправит папку `dist` в ветку `gh-pages`.

3. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка **`gh-pages`**, папка **`/ (root)`** → Save.

4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/school21-covers/`.

Для обновления сайта после изменений снова выполните `npm run deploy`.

В `vite.config.js` указано `base: './'`, поэтому пути относительные и сайт работает при любом имени репозитория — менять конфиг не нужно.

## Шаблон обложки

Шаблон лежит в `public/Cover_Template.png`. Если файла нет, приложение покажет ошибку «Не найден шаблон public/Cover_Template.png». Чтобы заменить шаблон, положите файл с тем же именем в папку `public/`.

Если у нового шаблона другой размер или линии стоят иначе, обновите объект `TEMPLATE` в `src/lib/cover.js`: `width`, `height`, `textX` (левый край текста), `lineRight` (правый край линий) и `lines` (Y-координаты линий ФИО, класса и года).

### Заголовок «ОКУУЧУНУН ИШИ»

На исходной фотографии был заголовок «СТУДЕНТТИН ИШИ». Первая строка заменена прямо в изображении `public/Cover_Template.png`, а не наложена поверх в коде:

- старая надпись удалена инпейнтингом по зелёному фону таблички;
- «ОКУУЧУНУН» нарисовано тем же типом шрифта (жирная антиква), с той же высотой букв, базовой линией, центровкой, белым цветом и мягким свечением;
- строка «ИШИ», золотая рамка, орнаменты и всё остальное — пиксели оригинала.

### Название школы и логотип

Название школы — «№21 ЖББ мектеби» (константа `SCHOOL` в `src/lib/cover.js`). Старая надпись «№21 Жалпы билим берүү мектеби» удалена из шаблона в обоих местах (под логотипом и в строке «Мектеп:»), а новое название рисуется на Canvas шрифтом PT Serif с теми же размером, цветом, выравниванием и положением.

Логотип: положите оригинальную эмблему школы в `tools/school21_logo.png` (PNG с прозрачностью или картинка на белом фоне) и пересоберите шаблон. Скрипт удалит старую эмблему, восстановит фон здания и поставит новую точно по центру, по кругу, без растяжения.

### Сборка шаблона

Исходная фотография сохранена в `tools/Cover_Template_original.png`. Пересобрать шаблон (заголовок, удаление старого названия школы, замена логотипа) можно скриптом (нужны Python 3, Pillow, numpy, opencv-python):

```bash
python3 tools/build_template.py
```

Папка `tools/` в сборку и на GitHub Pages не попадает.

## Как это работает

- **Предпросмотр** перерисовывается при каждом изменении полей.
- **Школа** («№21 ЖББ мектеби») вписывается автоматически под логотипом и в строку «Мектеп:». В форме она показана только для информации.
- **Шрифт** PT Serif встроен в проект (`@fontsource/pt-serif`), работает офлайн, поддерживает кириллицу, кыргызские ү, ң, ө и знак №. Размер подобран по ширине строки школы, напечатанной на исходном шаблоне.
- **Длинное ФИО** автоматически уменьшается, чтобы не выйти за линию.
- **Учебный год** проверяется по формату `2026–2027` (можно вводить с обычным дефисом).
- **PNG** — 2174 × 3072 px, рисуется на Canvas с удвоенным разрешением.
- **Word** — `.docx`, A4, книжная ориентация, поля 0, обложка на всю страницу. Изображение стоит «за текстом», поэтому Word не создаёт пустую вторую страницу.
- **Скачивание** через `file-saver`. Если данные изменились после генерации, кнопки скачивания блокируются до повторной генерации, чтобы не скачать устаревший файл.

Вместо `html-to-image` используется Canvas: он даёт точный размер 2174 × 3072 и одинаковый результат во всех браузерах.
